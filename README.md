# Smart Task Manager

**Plan your day. One task at a time.**

## About the Project

Smart Task Manager is a simple and user-friendly web application developed to help users organize and manage their daily activities. It allows users to add new tasks, mark tasks as completed, and delete tasks when they are no longer needed.

The application provides a clean interface with task counters to track the total number of tasks and completed tasks. It uses browser local storage to save task details, so tasks remain available after refreshing the page.

This project was developed as part of my beginner web development learning journey to gain practical experience with HTML, CSS, and JavaScript.

## Features

- **Add Tasks:** Enter and add new tasks to your daily list.
- **Complete Tasks:** Mark tasks as completed using checkboxes.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Task Counter:** Display the total number of tasks.
- **Completed Counter:** Track the number of completed tasks.
- **Local Storage:** Save tasks in the browser and retain them after refreshing.
- **Responsive Design:** Use the application on different screen sizes.
- **Interactive Interface:** Simple and clean design for easy task management.

## Technologies Used

- **HTML5** – Creates the structure of the application.
- **CSS3** – Provides styling, layout, colors, and responsive design.
- **JavaScript** – Implements task management functionality and updates the interface.
- **Browser Local Storage** – Stores task data locally in the browser.

## How to Use

1. Open the Smart Task Manager website.
2. Enter a task in the input box.
3. Click the **Add Task** button to add it to the list.
4. Select the checkbox when you complete a task.
5. Click **Delete** to remove a task.
6. Check the task counters to track your progress.
